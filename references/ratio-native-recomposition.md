# 普通比例的构图保持型适配

用于 `3:4`、`4:3`、`1:1`、`5:2`、`16:9`、`2.35:1` 等普通平台比例。精确 `2000×400` 的 `5:1` 改读 `wide-5x1-recomposition.md`。

## 锁定构图拓扑

必须保持：

- 标题完整文字、层级、原有换行和承载结构；
- 人物、手部、被持物、Logo 与核心物的动作和接触关系；
- 左右位置、前后遮挡和第一阅读顺序；
- 大人物、大标题、大核心物之间的面积等级；
- 人物身份、品牌事实、材质、光影和主色平衡。

允许对完整元素组做等比缩放、轻微平移、间距和安全区调整，以及低细节背景裁切或延展。禁止拆标题、改变换行、交换人物与 Logo 左右关系、拆断手与被持物或发明新视觉事件。

构图保持不等于把原版整体缩小后居中。主要内容要自然填满新画布；除非母图或用户明确需要留白，否则大块上下或左右空白均不通过。

## 硬文字清单

生成前逐字记录标题、副标题、品牌词、英文大小写、数字和符号。看不清时先询问，不得猜测。每张生成和每轮修正都沿用同一清单。

## 默认首轮

每个比例以满意母版为唯一视觉输入。多个目标可以并行提交。

```text
基于这张图做一个 X:X 的版本。保持原有构图、标题组合和元素关系，只做适应该比例所必需的等比缩放、轻微位移、间距调整和背景延展；让主要内容组自然填满目标画布，只保留正常安全边距，不要把整套内容缩小后居中并留下大块空白。图中已有文字必须逐字保持为：“<硬文字清单>”，不得改字、增字、漏字或生成近似字。
```

不要增加纵向递进、左右分区、三段节奏等新的构图导演。新比例的原生感来自原组合在新画布中的自然伸缩。

## 原尺寸 Review

结果返回后先保留原始文件，不制作总览或拼接图。每张必须与母版并排、按原尺寸依次检查：

1. 硬文字逐字准确；OCR 只能预警；
2. 构图拓扑与母版一致；
3. 内容密度适合目标画幅，没有无意义大留白；
4. 没有拥挤、贴边、误裁、重复残片、脸手异常或 Logo 变形；
5. 比例、尺寸和色彩正确。

通过项立即冻结。失败比例不得进入总览、拼接图或最终交付。

## 单点修正

从满意母版重新生成失败比例，只补一条修正。例如：

```text
保持其他内容不变，把底部标题整体向上移动一点，避免贴边。
```

```text
保持其他内容不变，把现有完整内容组整体适度放大并轻微纵向调整，消除上下大块空白，同时保留正常安全边距。
```

文字失败时必须列出全部硬文字并点名错误字。不要使用失败稿继续迭代。

若只有文字仍失败、其他构图已经通过，可以从满意母版提取受影响的完整标题组做原像素替换；只有能完整覆盖错误区域且不破坏遮挡、辉光、阴影和材质连续性时才执行。普通比例不得因此升级为 5:1 式分层重排。

## 速度策略

- 普通比例首轮并行生成；
- 不预先抠图、不建立母版适配包；
- 多个失败比例可并行重做；
- 只修失败比例，冻结所有通过项。
